Sistemas compatíveis

  • Windows: Windows 10 e Windows 11 de 64 bits (x64). Usa o Microsoft Edge WebView2, que já vem no Windows 11 e no Windows 10 atualizado; se faltar, o instalador o baixa. Windows 7 e 8 não são compatíveis.
  • macOS: macOS 10.13 High Sierra ou posterior, em Macs com Apple Silicon (M1, M2, M3, M4…) e Intel.
  • Linux: 64 bits (x86_64) com WebKitGTK 4.1: Ubuntu 22.04 ou posterior, Debian 12+, Linux Mint 21+, Fedora 38+, openSUSE, Arch e Manjaro.
  • Android (IHTML Mirror): Android 7.0 Nougat ou posterior, em celulares e tablets (ARM de 64 e 32 bits, e x86).

Qual eu escolho?

  • Windows: o instalador .exe é o mais simples. O .msi é para empresas que instalam software de forma centralizada.
  • Linux: o AppImage funciona em qualquer distribuição sem instalar (dê permissão de execução e abra). Use .deb no Debian/Ubuntu e .rpm no Fedora/openSUSE para instalar no sistema.
  • IHTML Mirror só é necessário para abrir arquivos .ihtml. Para publicar na web, o Editor exporta HTML comum que funciona em qualquer navegador.
