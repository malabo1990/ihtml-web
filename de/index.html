Funktionen

Alles, was der Editor kann.
Ohne Code zu schreiben.

Von der Keyframe-Timeline bis zu echter Physik: professionelle Web-Animation in einem Fenster.

◆ Timeline mit Keyframes

Mehrere benannte, unabhängige Animationen, Auto-Keyframe (REC), visuelles Easing, Aktions-Marker und Zwischenablage per Tastatur.

▣ Mehrere Artboards

Szenen auf derselben Leinwand, jede mit eigener Größe und eigenem Hintergrund; navigierbare Seiten mit Übergängen beim Export.

◎ Vollständiger visueller Inspector

Design, Data, Actions und Physik: Layout, Typografie mit Websuche für Schriftarten, Farbverläufe mit freiem Anfasser direkt auf der Leinwand (erscheint von selbst, ein Klick), Farbwähler im selben Popover, Hover/Active-Zustände, CSS-Klassen und mehr.

⚡ No-Code-Aktionen

Klick, Hover, Taste, Scroll, Verzögerung… zum Ein-/Ausblenden, Animieren, Abspielen von Timelines, Setzen von Variablen, zu Seiten springen und mehr.

≋ Echte Vektoren

Rechtecke, Ellipsen, Polygone und mit Pen gezeichnete Pfade: als echtes <svg> exportiert, mit Knotenbearbeitung, booleschen Operationen und Morphing per Keyframes.

🌐 8 Sprachen · 6 Themes

Übersetzbare Oberfläche (EN, ES, PT, FR, DE, IT, JA, ZH) und sechs Themes, hell und dunkel. Das sind reine Editor-Einstellungen, nie Teil der exportierten Datei.

🖥 Echte Performance

Die Animations-Engine positioniert mit transform (Compositor/GPU) statt left/top — sowohl im Editor als auch im exportierten HTML.

🔌 Öffentliche API

window.ihtmlDocument: steuere Animationen, Variablen und Aktionen des exportierten Ergebnisses aus deinem eigenen Skript oder einem <iframe>.

🤖 MCP für KI-Agenten

Ein echter MCP-Server: Claude Code (oder ein anderer MCP-Client) steuert den bereits geöffneten Editor direkt — erstellt und bearbeitet Elemente, wechselt Breakpoints, passt die Leinwand an und exportiert, ohne Klicks zu simulieren.

⬇ Import / Export

Importiert .ihtml (und alte .json), einfaches HTML, SVG und Designs aus Sketch, Penpot und EPUB. Exportiert einzelnes oder getrenntes HTML, Bild (PNG/WebP/JPEG), GIF und Video.

◈ Fertige Komponenten

Über 50 Elementtypen: Texte, Buttons, Inputs, Karten, Navbar, Pricing, Tabs, Slider, Canvas, Video, iFrames… mit echten HTML-Eigenschaften je Typ.

Das Format

Zwei Wege zum Teilen

Ein .html zum Veröffentlichen im Web, oder ein .ihtml, um ein interaktives Dokument zu senden, das sich mit IHTML Mirror öffnet.

🌐 Export HTML → das Web

Eine standardmäßige .html-Datei (einzeln oder getrennt in CSS+JS), mit eingebetteter Animations-Engine. Funktioniert in jedem Browser und Hosting, oder in einem <iframe>.

▶ .ihtml → IHTML Mirror

Die Datei, die du sendest: sie trägt das gesamte Projekt (Elemente, Animationen, Aktionen, Schriftarten, Bilder und Video). Wer sie erhält, öffnet sie mit IHTML Mirror, der kostenlosen App — Desktop oder Android.

✎ Dieselbe .ihtml-Datei lässt sich neu bearbeiten

Diese Datei ist zugleich das Ergebnis und die Quelle: öffne sie im Editor wieder und mach genau da weiter, wo du aufgehört hast. Kein separates Projektfile zum Verlieren.

Erste Schritte

Loslegen

Herunterladen, installieren, und du gestaltest schon. Kein Konto oder Verbindung nötig.

  1. Lade den Installer für dein System herunter und öffne IHTML.
  2. Ziehe Elemente aus dem Elements-Panel auf die Leinwand und stelle alles im Inspector rechts ein.
  3. Setze den Playhead auf die Timeline, tippe den Keyframe-Button einer Eigenschaft, bewege sie und tippe erneut: schon hast du eine Animation.
  4. Exportiere (kostenlos: Bild; vollständiger Plan: HTML und .ihtml). Für das Web Export HTML; um ein Dokument zu senden, eine .ihtml-Datei, die sich mit IHTML Mirror öffnet und weiter bearbeitbar bleibt.

Direkte Antworten

Das Wichtigste zu IHTML in vier kurzen Antworten.

Was ist IHTML?

IHTML (Interactive HTML) ist ein visueller Editor für HTML/CSS-Animationen: eine Leinwand mit Artboards, eine Timeline mit Keyframes, ein Eigenschafteninspector und No-Code-Aktionen. Es ist eine Desktop-App für Windows, macOS und Linux sowie eine App für Android; sie kann auch aus dem Quellcode im Browser ausgeführt werden.

Ist IHTML kostenlos?

Ja: Der Editor ist kostenlos und du kannst Bilder exportieren (PNG, WebP und JPEG). Das Abo für US$4/Monat — oder US$36/Jahr — ermöglicht den Import und Export von .html- und .ihtml-Dateien sowie GIF- und Video-Export; der kostenlose Plan exportiert kein HTML.

Was ist das .ihtml-Format?

Es ist das Dokumentformat von IHTML: Es trägt das gesamte Projekt eingebettet (Elemente, Animationen, Aktionen, Schriftarten, Bilder und Video). Es öffnet und läuft mit IHTML Mirror, der kostenlosen App für Desktop und Android, und dieselbe Datei lässt sich im Editor wieder öffnen, um weiter zu bearbeiten. Zum Veröffentlichen im Web nutzt man Export HTML, das eine standardmäßige .html-Datei erzeugt.

Brauche ich IHTML Mirror, um eine .ihtml-Datei anzusehen?

Ja: Eine .ihtml-Datei öffnet sich mit IHTML Mirror (kostenlos, Windows/macOS/Linux/ Android). Es ist wie ein PDF-Reader — wer die Datei erhält, installiert Mirror einmal und fertig. Wenn es stattdessen in jedem Browser ohne Installation funktionieren soll, exportiere mit Export HTML statt .ihtml.

Werden IHTML-Projekte auf einen Server hochgeladen?

Nein. Projekte leben auf deinem Rechner und der Editor funktioniert offline; es gibt keine Konten oder Backend. Exportiertes HTML funktioniert auf jedem Hosting oder als einzelne Datei. Die App enthält optionale Diagnose-Telemetrie (Fehler und Version, nie den Inhalt deiner Projekte), die sich in den Einstellungen abschalten lässt.
