Welche Datei brauche ich?

  • Windows: Der .exe-Installer ist am einfachsten. Das .msi ist für Firmen, die Software zentral verteilen.
  • Linux: Das AppImage läuft ohne Installation auf jeder Distribution (ausführbar machen und öffnen). Für eine Systeminstallation .deb unter Debian/Ubuntu und .rpm unter Fedora/openSUSE.
  • IHTML Mirror brauchst du nur zum Öffnen von .ihtml-Dateien. Fürs Web exportiert der Editor normales HTML, das in jedem Browser läuft.
