Pubblica sul web con Export HTML, oppure invia un .ihtml — un documento interattivo che si apre con IHTML Mirror e resta modificabile.

Funzionalità

Tutto quello che fa l'editor.
Senza scrivere codice.

Dalla timeline con keyframe alla fisica reale: animazione web professionale, in un'unica finestra.

◆ Timeline con keyframe

Diverse animazioni nominate e indipendenti, auto-keyframe (REC), easing visuale, marcatori di azione e copia/incolla da tastiera.

▣ Artboard multipli

Scene all'interno della stessa tela, ognuna con dimensione e sfondo propri; pagine navigabili con transizioni in fase di esportazione.

◎ Ispettore visuale completo

Design, Data, Actions e Fisica: layout, tipografia con ricerca di font web, sfumature con linea libera direttamente sulla tela (appare da sola, un clic), selettore colore unito allo stesso popover, stati hover/active, classi CSS e altro.

⚡ Azioni senza codice

Clic, hover, tasto, scroll, ritardo… per mostrare/nascondere, animare, riprodurre timeline, impostare variabili, andare a pagine e altro.

≋ Vettori veri

Rettangoli, ellissi, poligoni e path disegnati con Pen: esportati come <svg> reale, con editing dei nodi, operazioni booleane e morphing tramite keyframe.

🌐 8 lingue · 6 temi

Interfaccia traducibile (EN, ES, PT, FR, DE, IT, JA, ZH) e sei temi, chiari e scuri. Sono preferenze dell'editor, mai parte del file esportato.

🖥 Prestazioni reali

Il motore di animazione posiziona con transform (compositor/GPU) invece di left/top — sia nell'editor che nell'HTML esportato.

🔌 API pubblica

window.ihtmlDocument: controlla animazioni, variabili e azioni del risultato esportato dal tuo script o da un <iframe>.

🤖 MCP per agenti IA

Un vero server MCP: Claude Code (o un altro client MCP) controlla direttamente l'editor già aperto — crea e modifica elementi, cambia breakpoint, regola la tela ed esporta, senza simulare clic.

⬇ Import / Export

Importa .ihtml (e vecchi .json), HTML sciolto, SVG e design da Sketch, Penpot ed EPUB. Esporta HTML unico o separato, immagine (PNG/WebP/JPEG), GIF e video.

◈ Componenti pronti

Più di 50 tipi di elemento: testi, pulsanti, input, card, navbar, pricing, tab, slider, canvas, video, iframe… con proprietà HTML reali per ogni tipo.

Il formato

Due modi di condividere

Un .html per pubblicare sul web, oppure un .ihtml per inviare un documento interattivo che si apre con IHTML Mirror.

🌐 Export HTML → il web

Un file .html standard (unico o separato in CSS+JS), con il motore di animazione incorporato. Funziona in qualsiasi browser e hosting, o dentro un <iframe>.

▶ .ihtml → IHTML Mirror

Il file che invii: contiene l'intero progetto (elementi, animazioni, azioni, font, immagini e video). Chi lo riceve lo apre con IHTML Mirror, l'app gratuita — desktop o Android.

✎ Lo stesso .ihtml si rimodifica

Quel file è insieme il risultato e la fonte: riaprilo nell'Editor e riprendi esattamente da dove avevi lasciato. Nessun progetto separato da perdere.

IHTML Mirror

Il PDF che si muove

Mirror apre ed esegue un .ihtml. Pensalo come un PDF — ma con animazione, interazione e controllo su chi lo apre e fino a quando.

💼 Aziende

Proposte, cataloghi, report, onboarding — e pubblicità interattiva senza internet: portalo su una chiavetta USB a una fiera, uno stand o un negozio e si apre allo stesso modo. Invii un file, non un link.

🏥 Sanità

Materiali per i pazienti, moduli di consenso informato e guide alle procedure: animati, chiari e nella lingua necessaria. Il file .ihtml non dipende da un sito che potrebbe andare offline.

🎓 Istruzione

Libri e appunti interattivi, esercizi e presentazioni per la classe. Gli studenti li aprono senza account; con testo reale e ruoli ARIA, funzionano con screen reader e navigazione da tastiera.

🔐 Controllo della distribuzione

Ogni file .ihtml è pubblico, semi-privato o privato (crittografato con password, AES-256). Con data di scadenza opzionale per materiale che non dovrebbe circolare per sempre.

📦 Tutto incluso

Il file contiene font, immagini e video incorporati. Una volta che hai Mirror, si apre offline: né CDN, né font che non caricano, né link rotti.

🆓 Gratis per chi lo riceve

IHTML Mirror non costa nulla — come un lettore PDF. Chi crea si abbona per esportare; il destinatario installa solo Mirror e apre.

Come iniziare

Scarica, installa e stai già progettando. Non serve account né connessione.

  1. Scarica l'installer per il tuo sistema e apri IHTML.
  2. Trascina elementi dal pannello Elements sulla tela e regola tutto nell'Inspector a destra.
  3. Metti il playhead sulla Timeline, tocca il pulsante keyframe di una proprietà, spostalo e tocca di nuovo: hai già un'animazione.
  4. Esporta (gratis: immagine; piano Completo: HTML e .ihtml). Per il web, Export HTML; per inviare un documento, un .ihtml che si apre con IHTML Mirror e può essere modificato di nuovo.

Preferisci eseguirlo dal codice sorgente? Clona il repo e:

npm install
npm run dev

Apri l'URL stampato da Vite. Per creare il pacchetto dell'app desktop: npm run tauri:build.

Domande frequenti

Risposte dirette

L'essenziale di IHTML in quattro risposte brevi.

Cos'è IHTML?

IHTML (Interactive HTML) è un editor visuale di animazioni HTML/CSS: una tela con artboard, una timeline con keyframe, un ispettore di proprietà e azioni senza codice. È un'app desktop per Windows, macOS e Linux, e un'app per Android; può anche essere eseguita dal codice sorgente nel browser.

IHTML è gratuito?

Sì: l'editor è gratuito e puoi esportare immagini (PNG, WebP e JPEG). L'abbonamento di US$4/mese — o US$36/anno — abilita l'importazione e l'esportazione di file .html e .ihtml, oltre all'esportazione GIF e video; il piano Gratis non esporta HTML.

Cos'è il formato .ihtml?

È il formato di documento di IHTML: contiene l'intero progetto incorporato (elementi, animazioni, azioni, font, immagini e video). Si apre e viene eseguito con IHTML Mirror, l'app gratuita per desktop e Android, e lo stesso file si riapre nell'Editor per continuare a modificarlo. Per pubblicare sul web si usa Export HTML, che genera un file .html standard.

Ho bisogno di IHTML Mirror per vedere un .ihtml?

Sì: un file .ihtml si apre con IHTML Mirror (gratuito, Windows/macOS/Linux/Android). È come un lettore PDF — chi riceve il file installa Mirror una volta e basta. Se invece vuoi che funzioni in qualsiasi browser senza installare nulla, esporta con Export HTML invece di .ihtml.

I progetti IHTML vengono caricati su un server?

No. I progetti vivono sul tuo computer e l'editor funziona offline; non ci sono account né backend. L'HTML esportato funziona su qualsiasi hosting o come file singolo. L'app include una telemetria diagnostica opzionale (errori e versione, mai il contenuto dei tuoi progetti) che può essere disattivata nelle Impostazioni.
