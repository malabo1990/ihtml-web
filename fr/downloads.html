Lequel choisir ?

  • Windows : l’installateur .exe est le plus simple. Le .msi sert aux entreprises qui déploient les logiciels de façon centralisée.
  • Linux : l’AppImage fonctionne sur toute distribution sans installation (rendez-le exécutable et ouvrez-le). Utilisez .deb sur Debian/Ubuntu et .rpm sur Fedora/openSUSE pour l’installer sur le système.
  • IHTML Mirror n’est nécessaire que pour ouvrir les fichiers .ihtml. Pour publier sur le web, l’Editor exporte du HTML standard lisible dans tout navigateur.
