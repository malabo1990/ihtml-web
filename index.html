Características

Todo lo que hace el editor.
Sin escribir código.

Del timeline con keyframes a la física real: animación web profesional, en una sola ventana.

◆ Timeline con keyframes

Varias animaciones nombradas e independientes, auto-keyframe (REC), easing visual, marcadores de acción y portapapeles por teclado.

▣ Artboards múltiples

Escenas dentro de un mismo lienzo, cada una con su tamaño y fondo; Páginas navegables con transiciones al exportar.

◎ Inspector visual completo

Design, Data, Actions y Física: layout, tipografía con buscador de fuentes web, degradados con línea libre sobre el lienzo (se muestra sola, un solo clic), picker de color fusionado en el mismo popover, estados hover/active, clases CSS y más.

⚡ Acciones sin código

Click, hover, tecla, scroll, delay… para mostrar/ocultar, animar, reproducir timelines, setear variables, ir a páginas y más.

≋ Vectores de verdad

Rectángulos, elipses, polígonos y paths dibujados con Pen: se exportan como <svg> real, con edición de nodos, operaciones booleanas y morphing por keyframes.

🌐 8 idiomas · 6 temas

Interfaz traducible (EN, ES, PT, FR, DE, IT, JA, ZH) y seis temas, entre claros y oscuros. Son preferencias del editor, nunca del archivo exportado.

🖥 Rendimiento real

El motor de animación posiciona con transform (compositor/GPU) en vez de left/top — tanto en el editor como en el HTML exportado.

🔌 API pública

window.ihtmlDocument: controlá las animaciones, variables y acciones del resultado exportado desde tu propio script o un <iframe>.

🤖 MCP para agentes de IA

Servidor MCP real: Claude Code (u otro cliente MCP) controla el editor ya abierto directo — crea y edita elementos, cambia breakpoints, ajusta el lienzo y exporta, sin simular clics.

⬇ Import / Export

Importa .ihtml (y .json viejos), HTML suelto, SVG y diseños de Sketch, Penpot y EPUB. Exporta HTML único o separado, imagen (PNG/WebP/JPEG), GIF y video.

◈ Componentes listos

Más de 50 tipos de elemento: textos, botones, inputs, tarjetas, navbar, pricing, tabs, sliders, canvas, video, iframes… con propiedades HTML reales por tipo.

Dos maneras de compartir

Un .html para publicar en la web, o un .ihtml para enviar un documento interactivo que se abre con IHTML Mirror.

🌐 Export HTML → la web

Un .html estándar (único o separado en CSS+JS), con el motor de animación embebido. Funciona en cualquier navegador y hosting, o dentro de un <iframe>.

▶ .ihtml → IHTML Mirror

El archivo que enviás: lleva el proyecto entero (elementos, animaciones, acciones, fuentes, imágenes y video). Quien lo recibe lo abre con IHTML Mirror, la app gratuita — escritorio o Android.

✎ El mismo .ihtml se re-edita

Ese archivo es a la vez el resultado y la fuente: lo reabrís en el Editor y seguís exactamente donde lo dejaste. Sin proyecto suelto que perder.

Primeros pasos

Cómo empezar

Descargás, instalás y ya estás diseñando. No hace falta cuenta ni conexión.

  1. Descargá el instalador de tu sistema y abrí IHTML.
  2. Arrastrá elementos del panel Elementos al lienzo y ajustá todo en el Inspector de la derecha.
  3. Poné el cabezal en la Timeline, tocá el botón de keyframe de una propiedad, movelo y tocá de nuevo: ya tenés una animación.
  4. Exportá (gratis: imagen; plan Completo: HTML e .ihtml). Para la web, Export HTML; para enviar un documento, un .ihtml que se abre con IHTML Mirror y se puede volver a editar.

¿Preferís correrlo desde el código? Cloná el repo y:

npm install
npm run dev

Abrí la URL que imprime Vite. Para empaquetar la app de escritorio: npm run tauri:build.

Preguntas frecuentes

Respuestas directas

Lo esencial de IHTML en cuatro respuestas cortas.

¿Qué es IHTML?

IHTML (Interactive HTML) es un editor visual de animaciones HTML/CSS: lienzo con artboards, timeline con keyframes, inspector de propiedades y acciones sin código. Es una app de escritorio para Windows, macOS y Linux, y una app para Android; también se puede correr desde el código en el navegador.

¿IHTML es gratis?

Sí: el editor es gratis y podés exportar imágenes (PNG, WebP y JPEG). La suscripción de US$4 al mes — o US$36 al año — habilita el import y export de archivos .html e .ihtml y la exportación de GIF y video; el plan Gratis no exporta HTML.

¿Qué es el formato .ihtml?

Es el formato de documento de IHTML: lleva el proyecto completo incrustado (elementos, animaciones, acciones, fuentes, imágenes y video). Se abre y se ejecuta con IHTML Mirror, la app gratuita para escritorio y Android, y el mismo archivo se reabre en el Editor para seguir editando. Para publicar en la web se usa Export HTML, que genera un .html estándar.

¿Necesito IHTML Mirror para ver un .ihtml?

Sí: un .ihtml se abre con IHTML Mirror (gratis, Windows/macOS/Linux/Android). Es como un lector de PDF — quien recibe el archivo instala Mirror una vez y ya. Si en cambio querés que se vea en cualquier navegador sin instalar nada, exportá con Export HTML en vez de .ihtml.

¿Los proyectos de IHTML se suben a un servidor?

No. Los proyectos viven en tu equipo y el editor funciona sin conexión; no hay cuentas ni backend. El HTML exportado funciona en cualquier hosting o como archivo único. La app incluye telemetría de diagnóstico opcional (errores y versión, nunca el contenido de tus proyectos) que se puede desactivar en Configuración.
