ユーザーガイド — IHTML (Interactive HTML)

エディタでできることすべて：インターフェース、ベクター、アートボード、タイムライン、アクション、物理演算、エクスポートとインポート、キーボードショートカット、パブリックAPI。

1. はじめに

  1. IHTML（Windows、macOS、Linux、Android）をダウンロードしてインストールするか、リポジトリをクローンしてnpm installとnpm run devを実行します。
  2. 中央のキャンバスがシーンです（1つまたは複数のアートボード、下記参照）。上部バーには選択/作成ツール、左サイドバーにはLayers、右サイドバーは選択した要素のプロパティを扱うInspector、下部にはTimelineがあります。

言語とテーマ

右上、キャンバスツールの近くに2つのセレクタがあります：

  • 言語 — 8言語対応（English、Español、Português、Français、Deutsch、Italiano、日本語、中文）：メインナビゲーションとインスペクタ全体（Design/Data/Actions/物理演算）を翻訳します。
  • テーマ — ライトとダークの6つのテーマ（デフォルトはダークグレー）。

どちらもセッション間で記憶され（ブラウザに保存されます）、エディタの設定です—.ihtmlプロジェクトには保存されず、エクスポートされたHTMLにも反映されません。

要素の作成

上部バーのツール（または左のElementsパネル）を使ってテキスト、図形、ボタン、入力欄、カード、ナビバーなど既成のコンポーネントを追加します。新しい要素はバウンディングボックスが表示された選択状態で現れます。

上部バーのツール

ツール 機能
Select (V) 選択・ドラッグ。背景をドラッグすると複数選択の矩形が描かれます。
Shape (S) ドラッグでベクター長方形を描画。Altで楕円になります。
Text (T) クリックした場所にテキスト要素を作成します。
Zoom (Z) クリックでズームイン、Alt+クリックでズームアウト。
Hand (H) スペースバーを押さずにパンできます。
Pen (P) パスを手描きします（下記参照）。

ShapeとTextは作成後、自動的にSelectに戻ります。これにより次のクリックで誤って別の要素を作成することを防ぎます。

ベクター（描画された図形）

Shapeツールの図形と、ElementsパネルのShapesカテゴリのカード（Rectangle、Ellipse、Triangle、Polygon、Star、Spiral）は本物のベクター要素です：角丸のdivとしてではなく、本物の<path>を持つ<svg>としてエクスポートされます。Triangle/Polygonは正多角形（3辺と6辺）、Starは5つ星、Spiralは開いた螺旋として作成されます。辺・頂点の数は作成時に固定されます。異なる形が必要な場合はノードを手動で調整してください。

  • Fill、Stroke、Stroke widthはインスペクタのDataタブ内のElement Propertiesで編集します（塗りなしまたは線なしにするにはnoneを入力可能）—DesignのFill/Backgroundセクションではありません。ベクターの場合、そのセクションは表示すらされません：それは図形を囲む矩形の背景を色付けするもので、<path>自体ではないからです。
  • FillとStrokeにはフィールド横にカラーサンプルが付きます。テキストフィールドが引き続き操作を担います（塗りをなくすにはnoneと入力できます）。
  • 数値フィールド（Stroke width、スライダーのmin/max、Canvasのバッファなど）はドラッグして値を変更できます（フィールド横の⇄アイコン）：Shiftで微調整、Altで大きく変化します。
  • 要素をリサイズすると図形も拡大縮小されます：ジオメトリは独自の空間に存在し、viewBoxがそれをバウンディングボックスまで引き伸ばします。
  • 楕円はCSSの円ではなく、4つの本物のベジェセグメントとして保存されます。
  • Clip children to shape（Data > Element Properties）：このベクターの内部にネストされた要素は、多角形の領域外では見えなくなります—クリッピングマスクです（純粋なCSSのclip-path）。ベクターに子要素がある場合のみ効果があります。
  • Animate points（プロパティ末尾の◆ボタン）：ベクターはキーフレームで図形全体をアニメーションできます。ノードを編集した後、タイムラインの異なる位置でボタンを押すと、その形状がキーフレームとして記録されます。エディタは各ノードを個別に補間します（滑らかなモーフィング）。同じノード数を持つ2つの図形間でのみ正しく補間されます。

Penツール（パスの描画）

  • キャンバス上の各クリックは角（コーナー）の頂点を追加します。
  • クリック＆ドラッグすると、その頂点に対称のベジェハンドルが付きます—「柔らかい」ノードの典型的なジェスチャーです。
  • Enterでパスを開いたまま（線として）閉じます。
  • 最初の頂点の近くをクリックすると多角形として閉じます。
  • Escで描画全体を破棄します—要素は作成されません。

完了すると、パスは直接ノード編集モードに入ります。

既存ベクターのノード編集

任意のベクター要素をダブルクリックすると編集モードに入ります：ノードごとに白いドラッグ可能な点、ベジェハンドルごとに青い点が表示されます。

  • ノード（白）をドラッグすると移動します—曲線全体が一緒に動きます。
  • ハンドル（青）をドラッグするとその曲線のみ変化します。
  • Deleteで選択中のノードを削除します（有効なパスに必要な最小数を下回ることはありません：開いている場合は2、閉じている場合は3）。
  • Escで編集モードを終了し、通常のハンドルに戻ります。

移動・リサイズ・回転

  • ドラッグで移動、または矢印キー（Shift+矢印で10px）。複数選択している場合はグループ全体が一緒に動きます。
  • バウンディングボックスのハンドルでリサイズ：Shiftで比率維持、Altで中心から、Ctrlでグリッドにスナップ。
  • 丸いハンドルで要素を回転させます。
  • 回転/拡大縮小された親にネストされた要素は、画面軸ではなく自身の視覚的な軸に沿ってマウスや矢印キーに従います。
  • スマートスナップ：近くの要素の端・中心、または手動ガイドに自動的にスナップし、スナップ中はピンク/シアンのラインが表示されます。Ctrlでグリッドスナップを強制します（相互排他）。
  • ルーラーとガイド：キャンバス上部または左のグレーのバーからドラッグすると手動ガイド（シアンのライン）が作成されます。ダブルクリックで削除、ドラッグで再配置できます。

アートボード（複数の作業エリア）

同じキャンバス内に複数のアートボードを持つことができ、それぞれ独自のサイズと背景を持ちます。「Add Artboard」ボタン（またはアートボード背景のコンテキストメニュー）で、アクティブなものの隣に新しいものが作成されます。

  • アートボードの背景をクリックするとアクティブになります（新しい要素はそこに追加されます）。
  • ラベルをドラッグすると移動、角のハンドルをドラッグするとリサイズできます。
  • 何も選択していない状態で矢印キーを押すとアクティブなアートボードが移動します。Deleteを押すと（何も選択していない状態で）それを削除します（最後の1つは削除できません）。
  • Export HTMLは常にアクティブなアートボードのみをエクスポートし、プロジェクト全体ではありません。

コンテキストメニュー（右クリック）

共有された1つのメニューで、クリックした場所によってオプションが変わります：要素上（複製、削除、コピー/ペースト、前面/背面へ移動...）、空の背景（ペースト、すべて選択、アートボード追加）、特定のアートボードの背景（リネーム、複製、削除）、またはElementsパネルのカード（キャンバスに追加）。

  • 2つ以上選択時：選択全体を囲む矩形に対する整列グリッド（左/中央/右、上/中央/下）。
  • 3つ以上時：水平/垂直の間隔の均等配置も可能（最初と最後は固定され、残りが均等な間隔で配置されます）。
  • 2つ以上の兄弟ベクター選択時：SVGネイティブのfill-ruleとclip-pathを使ったブール演算グリッド（Union、Subtract、Intersect、Exclude）。結果は正確にレンダリングされ、他のベクターと同様にアニメーション/エクスポートできますが、ノード単位で編集可能な単一のシンプルな曲線としては残りません。

インスペクタ（右パネル）

Design、Data、Actions、物理演算の4つの排他的なタブ：一度に1つだけ表示されます。

  • Design — ビジュアルに関するすべてが1つの連続したスクロールにまとまっています：Position/Size/Origin/Spacing、Flex/Gridレイアウト（DisplayをFlexまたはGridにすると表示）、Appearance（Fill、Opacity、Blend Mode、Border、Radius、Shadow）、Typography（ウェブフォント検索、テキストカラー、テキストシャドウを含む）、Effects（scale、skew、3D、CSSフィルター）。各セクションはアコーディオンで、すでに独自の値がある場合のみ開いた状態で始まります。さらに、Fill/Opacity/Blend Mode/Border/Radius/Shadowは要素タイプに応じて適応します：ベクターはFill/Border/Radiusを表示しません（Data > Element Propertiesにあります）、テキストはBorder/Blend Modeを表示しません、画像/動画はFillを表示しません。セクションに実際の値がすでにある場合は表示されます—使用中の機能へのアクセスを失うことはありません。
  • Data — HTMLプロパティ：Element Info（ID/Type/Name）、Stateセレクタ（Normal/Hover/Active）、CSS Classes、Element Properties、Custom Attributes、Accessibility。
  • Actions — ノーコードインタラクション（セクション4参照）。
  • 物理演算 — 本物のシミュレーション（セクション4参照）。
詳細：StateセレクタはDataにありますが、そこで保存されるスタイル（色、タイポグラフィ、境界線、エフェクトなど）はDesignで編集します—Dataでステートを選び、Designに切り替えてください。

Display（Block/Flex/Grid）は3つのアイコンボタンで選択します。一般的でないバリエーション（Inline Block/Flex/Grid、None）は隣の「···」セレクタにあります。Flex/Gridレイアウト（Direction、Wrap、Justify、Align、Align Self）とStroke Style（Solid/Dashed/Dotted/Double）もアイコンボタンで選択します。
Columns/RowsのGridは、ドラッグ可能なトラックのリストとして編集します（「+ Track」で追加、×で削除、最小1つ）。autoやminmax(...)のような値は通常のテキストとして編集します。
Flex/Gridコンテナの子要素は親のレイアウトに実際に従い、幅・高さを維持します（暗黙に縮小することはありません）。

要素タイプ固有のプロパティ

DataでCSS Classesの下に、選択したタイプの実際のHTMLプロパティを持つElement Propertiesが表示されます。例：

要素 プロパティ
Range Slider Min, Max, Step, Value
Meter Min, Max, Value, Low, High, Optimum
Progress Value, Max
Inputs Type, Name, Required, Disabled, Read only
Textarea Name, Rows, Max length, Required, Disabled
Image / Picture Source, Alt text, Fit, Loading
Video / Audio Source, Controls, Autoplay, Loop, Muted, Poster
Link URL, Target, Rel
iFrame と embed Source, Title, Loading
Details / Dialog Open
Vector Fill, Stroke, Stroke width, Clip children
Marquee Direction, Behavior, Speed, Delay
Canvas Buffer width, Buffer height

このセクションは独自のプロパティを持たないタイプ（Div、Text）には表示されません。リストにないものは引き続きCustom Attributes（data-*、aria-*、role、title...）で編集できます。デフォルト値と同じ値は保存されず、エクスポートされたHTMLにも表示されません。

ローカルファイルのインポート（Image/Picture/Video/Audio）

Sourceフィールド（VideoではPosterも）にはChoose Fileボタンがあります：ファイルは本物のdata:URIとして埋め込まれます—外部サーバーに依存せず、あなたのコンピュータとウェブ間で持ち運びできます（アプリにはバックエンドがありません）。ブラウザやファイルエクスプローラーからコピーした画像をCtrl+Vで貼り付けることもできます：すでにImage/Picture/Videoが選択されている場合はそれを置き換え、そうでなければ新しいImageを作成します。エディタ内でコピーした要素を貼り付ける場合も同じように動作します（エディタはまずシステムのクリップボードに画像がないか確認します）。

装飾コンポーネントの編集可能テキスト

Badge、Avatar、Tooltip、Alert Box、Tab Bar、BreadcrumbはContentフィールド（Design）でテキストを編集します。Tab BarとBreadcrumbはカンマ区切りのリストを使用します—Overview,Pricing,FAQで3つのタブになります。Card、Pricing、Navbar、Paginationは固定のサンプルコンテンツのままです（独自のテキストが複数あり、専用の編集手段がまだありません）。Tooltipはその見た目をデザインするための静的なモックアップです。本物のツールチップにするにはActionsと組み合わせてください（hover → Show / mouseLeave → Hide、Tooltipは最初は非表示にしておく）。

セマンティックコンテナ（Header、Footer、Aside、Nav、Main...）

Semanticカテゴリ（Header、Nav、Main、Aside、Footer、Section、Article、Figure、Figcaption）は本物のHTMLタグとしてエクスポートされます（<header>、<aside>...）—SEO/アクセシビリティに重要です。5つのランドマーク（Header/Nav/Main/Aside/Footer）はアートボードの実際の端を占める状態で作成されます。これは出発点にすぎません：他の要素と同様に編集でき、独自の色や境界線は持ちません。

アクセシビリティ

Custom Attributesの下のAccessibilityセクションは任意の要素に適用できます：ARIA Label、ARIA Role（一般的なロールと「(automatic)」）、Hide from screen readers（aria-hidden）、Keyboard focusable（tabindex="0"）。この4つはすべて—キャンバス上でもエクスポートされたファイルでも—1行のJavaScriptも書かずに本物のHTML属性として出力されます。より具体的なもの（aria-describedby、aria-live...）にはCustom Attributesがあります。

Fill：単色、グラデーション、または画像

Fillフィールドはサマリーボタン（サンプル＋ラベル）で、Solid / Linear / Radial / Conic / Imageタブのポップオーバーを開きます：

  • Solid — 色とそのセレクタ。
  • Linear / Radial / Conic — ストップのリスト（0-100%の位置を持つ2色以上、「+ Add Stop」）、そしてAngle（Linear/Conic）またはCenter X/Y（Radial）。
  • Image — URLまたはローカルファイルのインポート（data:URI）。

カラーピッカー（Fill、Border、Shadow、Text Color、Text Shadow、ストップで共通）にはSaturation/Lightnessの四角形、HueとAlphaのスライダー（チェッカーボード背景付き）、そしてクリックでHEX → RGBA → HSLAを循環するテキストフィールドがあります—3つの形式のいずれかを貼り付けても機能します。Fill/Border/Text Color/Vector Fill-StrokeでSolidが有効な場合、ピッカーはポップオーバーのすぐ下に自動的に表示されます—小さなサンプルを別途開く必要なく、1クリックで全体を確認できます。

キャンバス上に直接表示されるグラデーションライン（Linear または Radial Fillを持つ要素）：Affinity Designerのように、ラインを描画に直接ドラッグします。ポップオーバーのAutomaticチェックボックス（デフォルトで有効）がオンの場合、LinearまたはRadialを選ぶと自動的に表示されます—他に何も押す必要はありません。Solidに戻すと非表示になります。Gキーは引き続き手動での表示/非表示切り替えとして機能します。Linear = ドラッグ可能な2つの端点（CSS構文の実際の制約をSVGグラデーションで回避し、ラインは矩形の中心に縛られなくなります）、Radial = 中心ハンドルと端ハンドル1つ（円で、楕円ではありません）。どちらのモードでもストップごとに1つの点があります（ドラッグで移動、ラインをダブルクリックでストップを追加）。Escで終了します。Angle/Center X/Yに数値を入力すると、従来の中心固定モードに戻ります。Conicは数値の角度フィールドを維持します。

ステート：Normal / Hover / Active

DataタブのCSS Classesの上に、3つのボタンのセレクタがあります。HoverまたはActiveを選択している間、Design内のTypography/Colors/Borders/Effects/Layoutで編集した内容はすべてそのステートに保存されます。キャンバスはリアルタイムでそれを表示します（選択された要素はそのステートを表示するよう「強制」されます）。JavaScriptなしで本物のCSSルールとしてエクスポートされます—#id:hover{...} / #id:active{...}。

制限：Position/Size/Originがステートの一部になることはありません。また、独自のコンテンツを持つ一部のタイプ（Button、Linkなど、独自の内部<button>/<a>を持つもの）では、その内部コンテンツの色/背景はステートでもクラスでも変更できません。DivやTextにはこの問題はありません。

2. レイヤー

左パネル（Layersタブ）は要素の階層を表示します。グループ化、分離、昇格/降格、z-indexによる並び替え（前面/背面への移動）ができます。

  • 通常のクリックは1つの要素のみを選択します。
  • Ctrl/Cmd+クリックで特定の要素を追加または削除します。
  • Shift+クリックで表示されている範囲を選択します（ネスト構造を尊重）。

Ctrl+C / Ctrl+X / Ctrl+Vでコピー、カット、ペーストできます（フォーカスがキャンバスまたはLayersにある場合）。子要素を持つ親をコピーすると、ペースト時にその関係が維持されます。複数回ペーストすると各コピーが少しずつずれて配置されます（重ならないように）。

ドラッグでネスト：ある要素を別の要素の上にドロップすると、その子になります。ただし、ドロップ先が本物の「void element」（<img>、<input>、<br>、<hr>...—コンテンツを持てない要素）の場合を除きます。そこにドロップすると兄弟として並び替えられます。他のタイプ（<div>、<button>、<section>、<a>...）は親になれます。

レイヤーのロックとガイドレイヤー（After Effectsスタイル）

  • ロック（Layersの各行の鍵アイコン）：その要素をキャンバスから選択、移動、リサイズ、回転できなくします—Layersパネル自体からは引き続き選択できます。
  • Mark as Guide Layer（コンテキストメニュー）：エディタでは表示・編集可能ですが、エクスポートされたHTML（とその子要素すべて）からは完全に除外されます—ルーラー、メモ、デザイン参照に便利です。

3. アニメーション（タイムライン）

レイヤーが多い場合、左側のリスト（名前）と右側のトラック（キーフレーム）は固定高さの帯の中で一緒に垂直スクロールします。

複数の独立した名前付きアニメーション

IHTMLでは独立した別々のタイムラインを持つことができます：

  • ヘッダーのセレクタにアクティブなアニメーションが表示されます。隣には「+」（Add Animation）（新規作成して名前を尋ねる）、鉛筆アイコン（Rename）、ゴミ箱アイコン（Delete）があります。最後の1つは削除できません（ボタンは無効化されます）。削除するとすべての要素でそのキーフレームが失われ、確認が求められます。
  • LoopとAutoは選択中のアニメーションに属します：Loopは終端に達すると最初から再開します（無効の場合、最後のフレームで停止）。Autoはエクスポートされたページの読み込み時に自動再生されます。新しいアニメーションは自動再生されません：複数持つ意味はPlay Timelineアクションでトリガーすることにあります。
  • キーフレームはアクティブなアニメーションにのみ紐付きます：同じプロパティでもアニメーションごとに異なるキーフレーミングが可能です。
  • アニメーションを切り替えるとタイムライン、キャンバス、プレイヘッドが更新されます。

タイムライン上のアクションマーカー

稲妻アイコンのボタン（またはルーラー下の細いバンドをダブルクリック）でプレイヘッドの位置にマーカーを追加します：訪問者が何も操作しなくても、再生がそのミリ秒に達するとアクションがトリガーされます。

  • インスペクタの同じActionsパネルで編集します（タイプは同じ。Triggerの行は消えます：「いつ」はマーカーの位置だからです）。
  • 同じパネルでドラッグして移動、Deleteで削除できます。
  • パスごとに1回発火します（Loopの場合、周回ごとに再度発火）。

プロパティのキーフレームを作成する

  1. 作業したいアニメーションを選択（または作成）します。
  2. 要素を選択し、アニメーションさせたいプロパティ（位置、透明度、色、スケールなど）の横にあるダイヤモンド（◆）をクリックしてそのプロパティのキーフレーム追跡を有効にします。
  3. タイムラインの別の位置に移動し（プレイヘッドをドラッグ）、値を変更します：Auto-Keyframeモード（赤い◆ボタン、ショートカットR）が有効な場合、自動的にキーフレームが作成されます。そうでない場合は「Add Keyframe at Playhead」を使用します。
  4. キーフレームをダブルクリックするとそのイージングカーブが循環します（linear、ease-in/out、cubic、back、bounce、elastic...）。
  5. Spaceで再生/一時停止、前後フレームのボタンでフレーム単位に進みます。総再生時間はDurフィールド（アニメーションごと）で制御します。

オートキーフレーム（REC）

Rが有効な場合、IHTMLは既に追跡中のプロパティを変更するたびにプレイヘッドの時刻にキーフレームを作成します—これにはベクターのノードとハンドルも含まれます（点やベジェハンドルをドラッグするとノード全体が記録されます）。RECが有効な間、右上に点滅する赤いバッジ（「● REC」）が表示されます。

キーフレームの選択、ドラッグ、コピー/ペースト

  • キーフレームをクリックすると選択、Shift+クリックで追加/削除、空白部分でのマーキーでその範囲すべてを選択します。
  • 2つの連続するキーフレームの間のフラットなバーも選択・ドラッグ可能です：間隔を維持したままセグメント全体を移動します。
  • プレイヘッドや他のキーフレームの近くにドラッグすると、その時刻に正確にスナップします（緑のガイド）。
  • Ctrl+C/Ctrl+Vで選択したキーフレームをプレイヘッドの時刻にコピー/ペーストします（イージングセレクタ横のCopy/Paste/Duplicateボタンに加えて）。複数ある場合、相対的な間隔が維持されます。

タイムラインのコンテキストメニュー（右クリック）

  • キーフレーム上：Copy、Duplicate、Delete、Interpolation（カーブのビジュアルグリッド）、Move to playhead。
  • セグメント上：Copy、Duplicate、Delete（両端にグループとして適用）。
  • トラックの空白部分：Paste（カーソル下の時刻に）。
  • 要素名の上：LayersやキャンバスのDと同じ要素メニュー。
  • ルーラー上：「Extend +1s」で総再生時間に1秒追加します。
エクスポート時：リストの最初のアニメーションはページ読み込み後すぐに自動再生されます。それ以外は「Play Timeline」アクションがトリガーするまで一時停止したままです。1つのアニメーションしかないプロジェクトは以前と同じように動作します。

ファイル（実際のフォルダと連携）

Timelineタブの隣にFilesがあります：Godot/Unreal/UnityのFileSystemパネルのように、あなたのコンピュータ上の実際のフォルダに直接連携したファイルマネージャーです。Choose folderでシステムのフォルダを選択します（セッションごとに一度）。ツリー内の画像、動画、音声をクリックすると新しい要素として直接キャンバスに追加されます。File System Access APIを使用しているため、現時点ではChrome/Edge/Operaのみ対応—FirefoxやSafariではボタンが無効表示され、注記が付きます。

4. インタラクティブアクション（ノーコード）

インスペクタのActionsタブで、エクスポートされたHTMLでユーザーが要素とインタラクトした際に何が起こるかをJavaScriptを書かずに定義します：

  • Trigger：クリック、ホバー、mouse enter/leave、ダブルクリック、On Drag Start / On Drag End（移動を伴わない単純なクリックはドラッグとしてカウントされません）、キー押下、スクロール、ビューポートへの進入、遅延後、ページ読み込み時。
  • Actions：表示/非表示/切り替え、CSSクラスの追加/削除/切り替え、CSSプロパティのアニメーション、特定の名前付きアニメーションの再生/一時停止/特定時刻への移動（「Animation」フィールド）、要素へのスクロール、インラインスタイルの固定、ページ遷移。
  • Target：要素自身、親コンテナ、すべての要素、または名前で選択された特定の要素（Targetセレクタは3つの固定オプションの下にLayersのすべての要素をリストします）。Play/Pause/Go to Time、Set Variable、Go to Pageには適用されません：これらはプロジェクト全体に対してグローバルです。
Key DownはKeyフィールドを使用します：そのキーでのみ発火し、フォーカスがテキストフィールドにある間は発火しません。After Delayはページ読み込みからカウントします。In Viewportは要素が画面に入るたびに発火します。

ページ（シーン）

左サイドバーのPagesタブはアートボードをナビゲート可能なページとしてリスト表示します—新しいデータではなく、専用のビューにすぎません。右クリック：アートボード背景と同じActivate/Rename/Duplicate/Deleteメニューです。

  • 「+ New page」でメニューが開きます：Blank page、またはレスポンシブプリセット（Tablet縦/横、Mobile縦/横）。
  • 別のページを選択している状態で作成されたTablet/Mobileプリセットは、そのページのレスポンシブバリアントとしてグループ化されます（PagesとLayersでインデントされます）。空白のページはネストされません。バリアントを複製すると親ページが維持されます。バリアントを持つページを削除すると、それらはルートに昇格します。
  • デフォルトでは選択中のページのみが表示されます（Layersにもそのレイヤーのみ）。「Selected only」/「All visible」ボタンで両方のビューが切り替わります。「All visible」では、他のページはキャンバス上に空の矩形として表示されます（位置/サイズ、モバイル、リサイズ可能、クリックでアクティブ化可能）が実際のコンテンツは表示されません。
  • Go to Pageアクションは現在のページを隠し、別のページをトランジション付きで表示します：Fade、Slide（4方向）、または瞬時（None）、ミリ秒単位の時間指定。エクスポートされたHTMLでは、プロジェクトがどこかでGo to Pageを使用している場合のみすべてのページが一緒にパッケージ化されます（初期ページ以外は非表示）—Go to Pageを使用しない複数アートボードのプロジェクトは常通りにエクスポートされます。

プロジェクト変数（カウンターと計算）

アクションのリストの上にProject Variablesがあります—プロジェクト全体の名前付き数値です。カウンター、スコア、フォームのステップなどに便利です。

  1. 「+ Add Variable」で変数を作成します（名前＋初期値。名前は文字、数字、アンダースコアに簡略化され、構文を壊すことはできません）。
  2. Set Variable (math)で編集します：どの変数か、どの操作か（= Set to、+ Add、− Subtract、× Multiply by、÷ Divide by、% Remainder of、⌃ Clamp min、⌄ Clamp max）、どの数値か。ゼロで割ると値は変更されません。
  3. 任意の要素のContentフィールドに{{名前}}と書くと表示されます：キャンバス上とエクスポートされたページ上で現在の値が見え、自動的に更新されます。どの変数とも一致しない名前はそのまま表示されるため、エラーに気付きやすくなっています。

完全なカウンターの例：変数score = 0、click → Set Variable → score → + Add → 1のボタン、そしてPoints: {{score}}のテキスト。変数を変更するアクションがない場合、その値は1行のJavaScriptもなくエクスポートされたHTMLに埋め込まれます。変数を表示する要素は、ネストされた子要素を持たない場合のみリアルタイムで再描画されます。

物理演算（本物のシミュレーション — 重力、衝突、バウンス）

インスペクタの物理演算タブは、Matter.jsエンジンを使って任意の要素に本物の物理挙動を与えます：

  1. 物理演算を有効化：その要素のシミュレーションをオンにします。
  2. ボディタイプ：Dynamic（落下、跳ね返り、他のボディやキャンバスの端と衝突）またはStatic（固定—床、壁、プラットフォームとして便利）。
  3. Shape：Rectangle または Circle（当たり判定の形状であり、見た目ではありません）。
  4. Bounce、Friction、Density：弾力性、滑りやすさ、重さ。
  • ボディは自身のページ/アートボード内に留まります：4つの端が見えない壁として機能します。
  • DynamicボディはエクスポートされたページやPreviewで掴んでドラッグできます。離すと本物の物理演算で動き続けます。Staticは「掴んでも」動きません。
  • 重要：物理演算は編集中はリアルタイムでシミュレートされません（ドラッグと競合しないよう、要素はそのX/Y位置で表示されます）。PreviewまたはエクスポートされたHTMLを開いたときに開始します。物理演算を使わないプロジェクトは追加のライブラリをダウンロードしません。

5. カスタムコード

上部バーに2つのコードボタンがあり、それぞれスコープが異なります：

  • 💻 Code Editor — 選択した要素のCSS/JS：要素にインラインで追加されるCSS、またはエクスポートされたHTMLでその要素をクリックしたときに実行されるスクリプト。
  • `</>` Live HTML/CSS — プロジェクト全体のHTMLとCSSのリアルタイムビュー（編集可能）：記述して「Apply Changes」をタップするとプロジェクトに反映されます。
    • 既存のidを持つタグはその要素を更新します（コンテンツ、属性、クラス、親）。
    • 新しいタグは実際の要素として作成されるためにdata-type="..."が必要です。それがない場合、警告と共に無視されます。
    • タグを削除するとその要素が削除されます。
    • CSSから削除したスタイルは要素から自動的には削除されません—インスペクタの該当セクションのリセットボタンを使用してください。
    • パネルが生成する形式と正確に一致しない手書きのグラデーション/フィルター/transformは無視されます（完全なCSSパーサーではなく、データモデルの往復ビューです）。
    • 「Refresh」は適用されていない変更をすべて破棄します。

6. エクスポート

2つの方法があります：ウェブに公開するためのExport HTMLと、IHTML Mirrorで開くドキュメントを送るためのExport（.ihtml）です。

  • 🌐 Export HTML — ウェブ向け（ホスティング、CMS、<iframe>...）：Single HTML file（プロジェクトデータを含まず、エンジンが埋め込まれた単一の自己完結型.htmlファイル—より軽量）またはSeparate HTML + CSS + JSを選択するダイアログ。この.htmlはどんなブラウザやホスティングでも動作します。
  • 💾 Export — project.ihtmlをダウンロードします：IHTMLのドキュメント。プロジェクト全体（要素、アニメーション、キーフレーム、アクション、レイヤー、フォント、画像、動画）が埋め込まれています。結果であり元データでもあります：受け取った人はIHTML Mirror（無料アプリ、デスクトップまたはAndroid）で開き、あなたはImportで再度開いてやめたところから正確に続けられます。 .ihtmlファイルはChromeでのダブルクリックを想定していません：形式を理解するMirrorが開きます。インストールなしでブラウザで動作させたい場合は、Export HTMLを使ってください。
  • ▶ Preview — 何もダウンロードせずに新しいタブで結果を開きます。エディタの現在の状態から生成されます。
  • 🖼 画像 / GIF / 動画のエクスポート — アートボードをラスタライズします：静止画像（PNG、WebP、JPEG）、アニメーションGIF、または動画（MP4、WebM）。FPSとスケールを選択できます。
  • 📱 モバイルプレビュー — QRコードを表示します。スマートフォンでスキャンするとリアルタイムでプロジェクトが見えます（同じネットワーク、編集中に自動再読み込み）。
プラン：無料プランでは静止画像（PNG/WebP/JPEG）のみエクスポート可能です。フルプランでは.htmlと.ihtmlのエクスポート、GIFと動画、Preview、モバイルのQRプレビューが追加されます。Settings › Planでライセンスキーを入力すると有効化されます。

どちらもエディタから独立しています：同じアニメーションエンジンから生成された最小限のランタイムのみを持ち運ぶため、結果はプレビューと全く同じようにアニメーションします。

.ihtmlファイルを開く：IHTML Mirrorから開きます（「Open project」ボタン、またはウィンドウにドラッグ）。Androidでは、（WhatsAppなどで）ファイルを受け取ったら、「開く」でIHTML Mirrorを選択します。エディタでは、Importで開いて編集できます。

7. インポート

📂 Importは.ihtml（埋め込まれたプロジェクトを自動検出）と、以前のバージョンのエディタからエクスポートされた.json（後方互換性）の両方を受け付けます。ファイルが期待される形式でない場合（elementsがない、または有効なJSON/.ihtmlでない）、エディタはその理由を説明するメッセージと共に拒否し、開いているプロジェクトには一切触れません。

さらに、IHTMLは他の形式からデザインを再構築し、新しいアートボード上の編集可能な要素として持ち込むことができます：

  • 本物のHTML（File Managerで.htmlを右クリック）：iframeで測定され、各ノードが階層とスタイルを維持したままIHTML要素になります。
  • SVG（図形、テキスト、画像）—Figmaのフレームを持ち込む推奨方法です（SVGとしてエクスポートしてください）。
  • Sketch（.sketch）、Penpot（.penpot）、EPUB書籍からのデザイン。

8. プロジェクト形式（.ihtmlに埋め込まれる、または旧.json）

構造のクイックリファレンス：

// project: name, version, artboards[], animations[], grid, classes
{
  "project": { "name": "My Project", "artboards": [ ... ], "animations": [ ... ], ... },
  "activeArtboardId": "artboard-1",
  "activeAnimationId": "anim-1",
  "elements": [
    {
      "id": "elem-172...-a1b2c", "type": "text",
      "parentId": null, "artboardId": "artboard-1",
      "styles": { "left": 100, "top": 50, "width": 300, ... },
      "keyframes": { "anim-1": { "opacity": [
        { "time": 0, "value": 0, "easing": "linear" },
        { "time": 1000, "value": 1, "easing": "easeOutCubic" } ] } },
      "actions": [ { "trigger": "click", "type": "toggleClass", ... } ]
    }
  ]
}

styles/keyframes内のすべての数値は単位なしです（"100px"ではなくleft: 100）。エディタがpx/degなどを追加します。インポート時、エディタは単位付きの値を正規化し、古いプロジェクト（単一アートボード、フラットなアニメーション）を自動的に移行します。

10. リアルタイムパブリックAPI

プロジェクトにアニメーションまたはアクションがある場合、エクスポートされたHTML/.ihtmlはwindow.ihtmlDocumentを公開します—ノーコード自体の外部から制御するための、安定した文書化されたパブリックAPIです（あなたのスクリプト、それを埋め込むページ、またはブラウザ自動化）： 

ihtmlDocument.playTimeline('Bounce'); // その名前付きアニメーションを再生
ihtmlDocument.pauseTimeline('Bounce');
ihtmlDocument.gotoTimeInTimeline(500, 'Bounce'); // ms, 名前
ihtmlDocument.isTimelinePlaying('Bounce'); // true/false
ihtmlDocument.timelineNames(); // ['Animation 1', 'Bounce', ...]
ihtmlDocument.getElementById('elem-172...'); // 本物のDOMノード
ihtmlDocument.triggerAction('elem-172...', 'click'); // その'click'アクションをトリガー
ihtmlDocument.triggerAction('elem-172...', 'keydown', 'Escape');

ihtmlDocument.getVariable('score'); // 現在の値
ihtmlDocument.setVariable('score', 10); // 変更し、{{score}}を再描画
ihtmlDocument.variableNames(); // ['score', ...]

名前はエディタで設定したもの（タイムラインのセレクタ、Project Variablesパネル）であり、内部IDではありません。

同一オリジンの<iframe>で埋め込む場合（埋め込むページとエクスポートされたファイルが同じドメインから配信されている場合）： 

const win = document.getElementById('miIframe').contentWindow;
win.ihtmlDocument.playTimeline('Bounce');
iframeが別のドメインにある場合、ブラウザはセキュリティ上の理由でこの直接アクセスをブロックします（IHTMLの制約ではありません）—その場合はpostMessageが必要ですが、まだ実装されていません。

11. MCP — AIエージェントによる制御

IHTMLはModel Context Protocol（MCP）サーバーを公開しており、AIエージェント—Claude Codeまたは他のMCPクライアント—がマウスクリックをシミュレートすることなく、既に開いているエディタ（開発中のブラウザまたはデスクトップアプリ）を直接制御できます。GodotやBlenderのようなエディタで既に使われているのと同じ仕組みです。

有効化するには、プロジェクトルートの.mcp.jsonファイルがサーバーを指定します：

{
  "mcpServers": {
    "ihtml-editor": { "command": "node", "args": ["bridge/mcp-server.js"] }
  }
}

エディタが開いている状態（ブラウザまたはデスクトップアプリ）で、エージェントは以下のようなツールを呼び出せます：

  • get_scene — アクティブなアートボードとすべての要素を読み取ります。
  • add_element / set_text / set_style / delete_element — 要素を作成・編集します（set_styleはブレークポイントを受け付け、基本値ではなくレスポンシブなオーバーライドを書き込みます）。
  • set_breakpoint / select_element — 実際のクリックと同じように、アクティブなブレークポイントや選択を変更します。
  • set_canvas_size / fit_canvas_height — アートボードをリサイズします（ブレークポイントごとの独自の高さ）、または実際のコンテンツに合わせます。
  • apply_template — カタログからテンプレートを読み込みます。
  • get_html — ファイルを書き込むことなく、プロジェクトがエクスポートするHTML/CSS/JSを返します。
現在のカバレッジ：要素の基本的な作成/編集、ブレークポイント、エクスポート。タイムライン/キーフレーム、Actions、物理演算、Symbols、Pages、Vectors、Dataには独自のMCPツールがまだありません。
