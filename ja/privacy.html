IHTML プライバシーポリシー

最終更新日: 2026年11月20日

本ポリシーは、お客様がウェブサイトを訪問し、サブスクリプションを購入し、または IHTML と IHTML Mirror アプリを使用する際に、IHTML（以下「管理者」）が処理するデータについて説明します。プライバシーに関するお問い合わせ先: malabo1990@gmail.com。

要約: ウェブサイトは Cookie を使用せず、IP アドレスも保存しません。アプリがプロジェクトの内容を送信することはありません。支払いは Stripe が処理し、当社がカード情報を見ることはありません。

1. ウェブサイト（ihtml.eu）

Cookie を使わない自社統計. ウェブサイトの訪問者数と IHTML のダウンロード数を把握するため、次の情報を記録します。

  • 閲覧したページ、言語、参照元のサイト（ドメインのみ。例: google.com）
  • 当社のプロバイダー（Cloudflare）が接続から推定したおおよその国と都市。IP アドレスは保存しません
  • デバイスの種類と OS（例:「モバイル、Android」）
  • ページが表示されていた時間と、ダウンロードボタンをクリックしたかどうか
  • ランダムなタブ識別子（sessionStorage）。タブを閉じると削除され、お客様が誰であるかは分かりません

Cookie、ブラウザーのフィンガープリント、第三者の統計・広告サービスは使用しません。ブラウザーで Do Not Track が有効な場合は何も記録しません。法的根拠: ウェブサイトの利用状況を集計して把握する正当な利益。保存期間: 400 日。その後自動的に削除されます。

ウェブサイトがブラウザーに保存するもの. 選択した言語とテーマ（ライト/ダーク。次回も同じ表示で開くための localStorage）と、上記のタブ識別子（sessionStorage）だけです。これらは Cookie ではなく、当社に送信されることはなく、ブラウザーの設定から削除できます。サイト上の小さなお知らせでこのことを説明しており、お知らせを閉じたことも localStorage に記録されます。

ホスティング. ウェブサイトは GitHub Pages、統計は Cloudflare でホストされています。他のウェブサーバーと同様に、ページの配信と不正利用からの保護のため、各社のプライバシーポリシーに従って IP を技術的かつ一時的に処理する場合があります。

2. サブスクリプションの購入（Stripe）

支払いは Stripe Payments Europe, Ltd. が処理します。登録時に Stripe は、メールアドレス、氏名、支払い情報、および税金の計算に必要な国または住所を収集します。当社がカード情報を受け取ったり保存したりすることはありません。 当社は Stripe から、氏名、メールアドレス、国、サブスクリプションの状態、金額を受け取ります。

法的根拠: 契約の履行および法的義務（会計・税務）。保存期間: サブスクリプションの期間中、その後は会計・税務記録について法律で定められた期間（通常 6 年）。

3. IHTML Pro ライセンス

Pro の有効化と更新のため、アプリは当社のライセンスサーバー（Cloudflare 上）にライセンスキーと、お客様のデバイスで生成され個人データを含まないランダムなデバイス識別子を送信します。有効化されたデバイス（最大 2 台）はお客様の Stripe サブスクリプションに保存されます。サーバーは、アプリに表示するためにお客様の氏名（またはメールアドレス）を含む署名付きの許可証を返します。法的根拠: 契約の履行。保存期間: サブスクリプションの期間中。

4. アプリ（IHTML と IHTML Mirror）

  • プロジェクトはお客様のデバイス上に保存されます。当社が受け取ることはありません。
  • バージョン 1.0 はテレメトリーを送信しません。 将来のバージョンで診断テレメトリーを追加する場合、それは匿名であり、プロジェクトの内容、IP、氏名、メールアドレスを含まず、設定 › 診断で無効化できます。その前に本ポリシーを更新します。
  • アプリがインターネットに接続するのは、Pro ライセンスの確認と、お客様がプロジェクトに含めたもの（YouTube 動画など）のためだけです。

5. フォーラムとお問い合わせ

フォーラムは GitHub Discussions でホストされ、GitHub のプライバシーポリシーが適用されます。そこに投稿した内容は公開されます。メールでお問い合わせいただいた場合、データは返信のためにのみ使用します。

6. データの共有先

サービスの運営に必要なプロバイダーとのみ共有し、各社はその役割に応じて処理者または管理者として行動します: Stripe（支払い）、Cloudflare（ライセンスサーバーと統計）、GitHub（ウェブサイト、ダウンロード、フォーラム）。一部は米国にあり、移転は EU-米国データプライバシーフレームワークまたは標準契約条項に基づきます。当社はお客様のデータを販売せず、広告にも使用しません。

7. お客様の権利

malabo1990@gmail.com までご連絡いただくことで、データへのアクセス、訂正、削除、異議、制限、データポータビリティを請求できます。当社の対応が適切でないと思われる場合は、スペインデータ保護庁（aepd.es）またはお住まいの地域の監督機関に苦情を申し立てることができます。

8. 変更

本ポリシーを変更する場合は、新しい版を日付とともにここに掲載します。重要な変更はウェブサイトまたはアプリで告知します。

相違がある場合は、本ポリシーのスペイン語版が優先します。
