機能

エディタでできること、すべて。
コードを書かずに。

キーフレームタイムラインから本物の物理演算まで：プロフェッショナルなウェブアニメーションを、ひとつのウィンドウで。

◆ キーフレームタイムライン

複数の独立した名前付きアニメーション、オートキーフレーム（REC）、ビジュアルイージング、アクションマーカー、キーボードでのコピー＆ペースト。

▣ 複数アートボード

同じキャンバス内に複数のシーン、それぞれ独自のサイズと背景を持つ。エクスポート時のトランジション付きナビゲーション可能なページ。

◎ 完全なビジュアルインスペクタ

Design、Data、Actions、Fisica：レイアウト、ウェブフォント検索付きタイポグラフィ、キャンバス上に直接引けるグラデーションライン（自動で表示、ワンクリック）、同じポップオーバーに統合されたカラーピッカー、hover/activeステート、CSSクラスなど。

⚡ ノーコードアクション

クリック、ホバー、キー、スクロール、ディレイ…で表示/非表示、アニメーション、タイムライン再生、変数設定、ページ遷移などを実行。

≋ 本物のベクター

長方形、楕円、多角形、Penツールで描いたパス：本物の<svg>としてエクスポート、ノード編集、ブール演算、キーフレームによるモーフィングに対応。

🌐 8言語 · 6テーマ

翻訳可能なインターフェース（EN、ES、PT、FR、DE、IT、JA、ZH）と6つのライト/ダークテーマ。エディタの設定であり、エクスポートされたファイルには含まれません。

🖥 実際のパフォーマンス

アニメーションエンジンはleft/topではなくtransform（コンポジター/GPU）で位置を決定します—エディタでもエクスポートされたHTMLでも同様です。

🔌 パブリックAPI

window.ihtmlDocument：あなたのスクリプトや<iframe>からエクスポート結果のアニメーション、変数、アクションを制御。

🤖 AIエージェント向けMCP

本物のMCPサーバー：Claude Code（または他のMCPクライアント）が既に開いているエディタを直接操作します—要素の作成・編集、ブレークポイントの変更、キャンバス調整、エクスポートまで、クリックをシミュレートせずに。

⬇ インポート / エクスポート

.ihtml（と旧.json）、単独のHTML、SVG、Sketch・Penpot・EPUBからのデザインをインポート。単一または分割HTML、画像（PNG/WebP/JPEG）、GIF、動画をエクスポート。

◈ すぐ使えるコンポーネント

50種類以上の要素タイプ：テキスト、ボタン、入力欄、カード、ナビバー、プライシング、タブ、スライダー、キャンバス、動画、iframe…それぞれ本物のHTMLプロパティ付き。

仕組み

エディタの内側

キャンバス、タイムライン、インスペクタがひとつのウィンドウに。追いかける必要のあるフローティングパネルはありません。

ファイル形式

2つの共有方法

ウェブに公開するための.html、またはIHTML Mirrorで開けるインタラクティブなドキュメントを送るための.ihtml。

🌐 Export HTML → ウェブへ

標準的な.htmlファイル（単一またはCSS+JS分割）で、アニメーションエンジンが埋め込まれています。どんなブラウザやホスティングでも、<iframe>内でも動作します。

▶ .ihtml → IHTML Mirrorへ

送信するファイル：プロジェクト全体（要素、アニメーション、アクション、フォント、画像、動画）を含みます。受け取った人は無料アプリIHTML Mirror（デスクトップまたはAndroid）で開きます。

✎ 同じ.ihtmlを再編集

そのファイルは結果でもあり元データでもあります：エディタで再度開けば、やめたところからそのまま続けられます。別のプロジェクトを失う心配はありません。

始め方

ダウンロードしてインストールすれば、すぐにデザインを始められます。アカウントも接続も不要です。

  1. あなたのシステム向けのインストーラーをダウンロードしてIHTMLを開きます。
  2. Elementsパネルから要素をキャンバスにドラッグし、右側のInspectorですべてを調整します。
  3. Timeline上でプレイヘッドを動かし、プロパティのキーフレームボタンを押し、位置を変えてもう一度押します：これでアニメーションの完成です。
  4. エクスポート（無料：画像；フルプラン：HTMLと.ihtml）。ウェブ向けにはExport HTML、ドキュメントを送るならIHTML Mirrorで開ける.ihtmlを選んでください。再編集も可能です。

ソースコードから実行したいですか？リポジトリをクローンして：

npm install
npm run dev

Viteが表示するURLを開いてください。デスクトップアプリのパッケージを作るには：npm run tauri:build。

ストレートな回答

IHTMLの要点を4つの短い回答で。

IHTMLとは何ですか？

IHTML（Interactive HTML）はHTML/CSSアニメーションのビジュアルエディタです。アートボード付きキャンバス、キーフレームタイムライン、プロパティインスペクタ、ノーコードアクションを備えています。Windows、macOS、Linux向けのデスクトップアプリと、Android向けアプリがあり、ソースコードからブラウザで実行することもできます。

IHTMLは無料ですか？

はい。エディタは無料で、画像（PNG、WebP、JPEG）をエクスポートできます。月額4ドル—または年額36ドル—のサブスクリプションで.htmlと.ihtmlファイルのインポート/エクスポート、GIFと動画のエクスポートが可能になります。無料プランではHTMLをエクスポートできません。

.ihtml形式とは何ですか？

IHTMLのドキュメント形式で、プロジェクト全体（要素、アニメーション、アクション、フォント、画像、動画）が埋め込まれています。デスクトップとAndroid向けの無料アプリIHTML Mirrorで開いて実行でき、同じファイルをエディタで再度開いて編集を続けられます。ウェブに公開するには標準の.htmlファイルを生成するExport HTMLを使用します。

.ihtmlファイルを見るにはIHTML Mirrorが必要ですか？

はい。.ihtmlファイルはIHTML Mirror（無料、Windows/macOS/Linux/Android）で開きます。PDFリーダーのようなものです—ファイルを受け取った人は一度Mirrorをインストールするだけです。インストールなしでどのブラウザでも動作するようにしたい場合は、.ihtmlの代わりにExport HTMLでエクスポートしてください。

IHTMLのプロジェクトはサーバーにアップロードされますか？

いいえ。プロジェクトはあなたのコンピュータ内にあり、エディタはオフラインで動作します。アカウントやバックエンドはありません。エクスポートされたHTMLはどんなホスティングでも、単一ファイルとしても動作します。アプリにはオプションの診断テレメトリ（エラーとバージョンのみ、プロジェクトの内容は含まれません）があり、設定で無効化できます。
