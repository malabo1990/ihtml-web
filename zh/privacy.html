IHTML 隐私政策

最后更新：2026 年 11 月 16 日

本政策说明当您访问网站、购买订阅或使用 IHTML 和 IHTML Mirror 应用时，IHTML（“控制者”）会处理哪些数据。任何隐私问题请联系：malabo1990@gmail.com。

简而言之： 网站不使用 Cookie，也不保存您的 IP；应用从不发送您项目的内容；付款由 Stripe 处理，我们从不会看到您的银行卡。

1. 网站（ihtml.eu）

无 Cookie 的自有统计。 为了解有多少人访问网站并下载 IHTML，我们会记录：

  • 访问的页面、语言以及来源网站（仅域名，例如 google.com）；
  • 由我们的服务商（Cloudflare）根据连接推断的大致国家和城市；不保存您的 IP 地址；
  • 设备类型和操作系统（例如“手机，Android”）；
  • 页面可见的时长以及您是否点击了下载按钮；
  • 一个随机的标签页标识符（sessionStorage），关闭标签页即删除，无法识别您的身份。

我们不使用 Cookie、浏览器指纹，也不使用第三方统计或广告服务。如果您的浏览器启用了 Do Not Track，则不会记录任何内容。法律依据：了解网站整体使用情况的正当利益。保存期限：400 天，之后自动删除。

托管。 网站托管在 GitHub Pages，统计托管在 Cloudflare。与任何网络服务器一样，它们可能根据各自的隐私政策，出于提供页面和防止滥用的目的，以技术性和临时的方式处理您的 IP。

2. 购买订阅（Stripe）

付款由 Stripe Payments Europe, Ltd. 处理。订阅时，Stripe 会收集您的电子邮件、姓名、付款信息以及计算税费所需的国家或地址。我们从不接收或存储您的银行卡信息。 我们从 Stripe 获得您的姓名、电子邮件、国家、订阅状态和金额。

法律依据：履行合同和法律义务（会计和税务）。保存期限：订阅期间，之后按法律对会计和税务记录要求的期限保存（通常为 6 年）。

3. IHTML Pro 许可

为激活和续订 Pro，应用会向我们的许可服务器（位于 Cloudflare）发送许可密钥和一个在您设备上生成、不含个人数据的随机设备标识符。已激活的设备（最多 2 台）保存在您的 Stripe 订阅中。服务器会返回一份包含您姓名（或电子邮件）的签名许可，以便在应用中显示。法律依据：履行合同。保存期限：订阅期间。

4. 应用（IHTML 和 IHTML Mirror）

  • 您的项目保存在您的设备上。我们从不会接收到它们。
  • 1.0 版本不发送任何遥测数据。 如果未来版本加入诊断遥测，它将是匿名的，绝不包含您的项目内容、IP、姓名或电子邮件，并可在设置 › 诊断中关闭。届时会事先更新本政策。
  • 应用仅在验证 Pro 许可以及加载您在项目中包含的内容（例如 YouTube 视频）时连接互联网。

5. 论坛和联系

论坛托管在 GitHub Discussions，受 GitHub 隐私政策约束：您在那里发布的内容是公开的。如果您给我们写信，我们仅会使用您的数据进行回复。

6. 我们与谁共享数据

仅与提供服务所必需的服务商共享，他们根据各自角色作为处理者或控制者：Stripe（付款）、Cloudflare（许可服务器和统计）以及 GitHub（网站、下载和论坛）。其中部分位于美国；数据传输依据欧盟-美国数据隐私框架或标准合同条款。我们不出售您的数据，也不将其用于广告。

7. 您的权利

您可以写信至 malabo1990@gmail.com，要求访问、更正、删除、反对、限制处理以及携带您的数据。如果您认为我们未妥善处理您的请求，可以向西班牙数据保护局（aepd.es）或您当地的监管机构投诉。

8. 变更

如果我们修改本政策，将在此发布注明日期的新版本。重大变更将在网站或应用中公布。

如有歧义，以本政策的西班牙语版本为准。
